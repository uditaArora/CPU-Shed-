4 Scheduling Algorithms

Each with interactive simulation and detailed explanation

FCFS

First Come First Serve

Processes execute in the order they arrive. Simple, fair, but can cause the convoy effect.

O(n log n)Sort
Non-preemptiveType
 SJF

Shortest Job First

Picks the shortest burst time next. Optimal average wait time but can cause starvation.

O(n²)Sort
Non-preemptiveType
 RR

Round Robin

Each process gets a fixed time quantum. Great for time-sharing and fairness.

O(n)Per cycle
PreemptiveType
 Priority

Priority Scheduling

Highest priority (lowest number) runs first. Flexible but risks starvation without aging.
